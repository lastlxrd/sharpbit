# SharpBit

SharpBit converts PNG, JPG, BMP and WebP images into monochrome 1-bit C assets.
It also creates previews decoded from the exact generated bytes.

## Setup

```bash
python -m pip install -r requirements.txt
```

## Use

1. Put images into `input/`.
2. Run:

```powershell
.\convert-assets.bat
```

Linux/macOS:

```bash
./convert-assets.sh
```

3. Get the results from:

```text
output/generated/assets.c
output/generated/assets.h
output/preview/
```

Conversion settings are stored in `config.json`. The default output is MSB-first
with black pixels stored as `1`.
